# IA como processo — kit para começar

Material prático da palestra **"IA como processo, não só ferramenta"** (25/11/2026).

**Página do kit:** https://samuelsilva-sp.github.io/ia-como-processo/
**Baixar tudo:** botão verde **Code › Download ZIP**, aqui no GitHub.

## Comece por aqui
👉 [comece-aqui.md](comece-aqui.md): os cinco passos para segunda-feira e oito perguntas para escolher o primeiro processo.

## O que tem dentro

```
comece-aqui.md                 ← os 5 passos
gestor/                        ← para quem lidera a mudança, sem programar
  prompts-qualquer-ia.md       ← o método no ChatGPT, Gemini e Claude.ai
  mapa-de-processo.md / .xlsx  ← o que é da IA e o que é do analista
  ficha-do-agente.md           ← missão, dono, limites e evolução de cada agente
  prompts-por-area.md          ← ideias em fiscal, contábil, DP, societário e atendimento
construtor/                    ← para quem vai montar no Claude Code
  como-instalar.md
  CLAUDE.md-modelo.md          ← as regras de trabalho para a IA
  skills/                      ← /research /plan /break /implement /review
seguranca/
  checklist.md                 ← local, web, automações, agentes e LGPD
referencias.md                 ← créditos, fontes e citações
```

## O método
**Research** (entender) → **Plan** (o contrato) → **Break** (tarefas pequenas) → **Implement** (uma por vez) → **Review** (revisão antes de aprovar).
A IA nunca avança de etapa sozinha: você aprova entre elas.

> Processo para a IA. Decisão para o analista.
