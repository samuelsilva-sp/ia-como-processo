# Referências e créditos

## Inspiração do método
- **Deborah Folloni** — o workflow Spec → Break → Plan → Execute, que inspirou a evolução do nosso Research → Plan → Implement para as etapas Break e Review.
  - Vídeo: https://www.youtube.com/watch?v=Ea5yaWGqoHQ
  - Artigo "Meu novo workflow (Claude Code + Epic)": https://dfolloni.substack.com/p/meu-novo-workflow-claude-code-epic
- **João Vitor Chaves (G4)** — palestra sobre IA como força de trabalho nas empresas: delegar à IA como a uma pessoa, assistente × agente, processo → resultado → indicador, "organograma" e "PDI" da IA.
  - Vídeo: https://www.youtube.com/watch?v=PzNNFxg-dng
- **Anthropic** — guias oficiais:
  - "Building effective agents" (dez/2024): https://www.anthropic.com/engineering/building-effective-agents
  - "Claude Code best practices" (abr/2025): https://www.anthropic.com/research/claude-code-best-practices
